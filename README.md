# Exemplo de Site Conversível

Case educacional de uma página de vendas curta para Facebook Ads, baseada no modelo visual apresentado no curso.

## Como personalizar

- Troque os textos entre colchetes pela copy do produto.
- Substitua os blocos “Aqui vai uma imagem” pelas imagens reais.
- Insira o player vertical no bloco `.video-shell`.
- Adicione o link do checkout ao botão de compra quando a página deixar de ser apenas um exemplo.

As cores, a fonte Poppins, as proporções e a estrutura visual já estão configuradas no arquivo `index.html`.
